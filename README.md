### Java e Sua História
A Sun Microsystems financiou uma pesquisa interna com o codinome Green em 1991. O projeto resultou no desenvolvimento de uma linguagem baseada em C e C++ que seu criador , James Gosling, chamou de Aok (carvalho) em homenagem a árvore que dava para vê pela janela do seu escritório na Sun, depois de um tempo foi descoberto que já havia uma linguagem de computador chamada Oak. Quando uma equipe da Sun visitou uma cafeteria local, o nome Java (cidade de origem de um tipo de café importado) foi sugerido e pegou.

Java é agora utilizada praticamente em todo lugar :

    • Páginas da Web com conteúdo interativo e dinâmico ;
    • Aplicações corporativas de grande porte ;
    • Softwares destinados ao consumidor final.
    • Aplicativos para smartphone.
